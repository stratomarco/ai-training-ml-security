# AI Training: ML Security v1.4.0

This release improves learner delivery and adds a bounded, optional AIGoat v2.0 extension for two MCP trust boundaries. The required 40-hour path is unchanged: BrokenPilot remains the primary LLM, RAG, agent, privacy, red-team, and capstone target. The toy classifier and MLOps evidence review retain their established roles. Qwen3, AIGoat, and rubrics remain optional.

## What changed since v1.3.0

- Module 07 now links to an original course exercise that reviews AIGoat's MCP03-2 tool-redefinition and MCP07-1 credential-scoping cases from pinned v2.0 source. Students can complete the review without installing AIGoat.
- Windows learners can optionally run those same two comparisons through a course launcher and Compose profile. The launcher verifies the upstream commit, generates a local session secret, and builds from the complete WSL source so Windows-incompatible media filenames are preserved.
- The optional AIGoat stack publishes only its frontend on `127.0.0.1:3000`. Its backend has no host port, runs on an internal Docker network as UID and GID 10001, uses a read-only root filesystem, drops all Linux capabilities, and enables `no-new-privileges`.
- The 40-hour student workbook now links each day directly to the relevant modules, labs, journal, and final-report template. The course site labels 40-hour navigation consistently.
- Site pages now map their edit links back to the canonical repository source. CI and the final release gate verify that every generated content page has exactly one valid source edit link.
- Instructor materials now include a participant brief and observation form for an eventual independent v1.3.0 field pilot. These are historical pilot materials and remain useful for evaluating the stable required path.
- The toy classifier includes a Python 3.12 Docker fallback. Its test dependency was updated after repository security review.

## Validation

The final release gate checks repository structure, content readiness, lab targets, workflow configuration, strict MkDocs navigation, source edit links, BrokenPilot, the toy classifier, and the offline artifact-promotion cases. GitHub pull request checks run the repository gate, Windows artifact checks, and Docker smoke tests before the release commit reaches `main`.

The selected AIGoat route was also replayed in an isolated Docker project with a new database and local configuration on one Windows and Docker Desktop host. Both selected exercises produced their intended vulnerable and protected comparisons. The 28 visible storefront images loaded, the backend security settings matched the Compose profile, the frontend listener remained on loopback, and teardown removed the test containers and listener.

## Limits and license boundary

AIGoat is an independently maintained project and is not bundled into this repository. This course pins and credits its v2.0 release, links to upstream source, and supplies original review questions and a local launcher. AIGoat's own licenses continue to govern its platform and training material. The supported course use is credited noncommercial self-study. Paid use of AIGoat labs or prompts requires separate permission from its maintainers.

The AIGoat live route is optional and intentionally narrow. Validation used one maintainer-operated Windows host and cached Docker layers. It does not establish a cold first-time learner install, macOS or native Linux support, every upstream exercise, or model-driven agent behavior. Upstream dependencies remain broad and the backend image is large. The source-review route remains the lower-cost option, and BrokenPilot remains the required course environment.

The course still needs feedback from an independent first-time student and instructor. Automated gates establish repository and lab behavior within their tested scope; they do not prove learning outcomes or classroom usability.
