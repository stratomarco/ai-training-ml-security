# AI Training: ML Security v1.2.0

This stable teaching release makes BrokenPilot the primary local lab for the LLM, RAG, agent, privacy, red-team, and capstone path. It retains the 12-module course architecture. The toy classifier and static MLOps evidence pack cover their separate topics. DVAIA remains optional external practice, and rubrics are optional feedback aids.

## What changed since v1.1.0

- Added a guided BrokenPilot browser workspace, resettable fake tickets/documents/memory, and a ticket-to-retrieval-to-agent exercise with visible before-and-after state.
- Added named vulnerable and controlled profiles for retrieval, injection, output encoding, tool authorization, approval, and memory. Security decisions are demonstrated at application boundaries; the marker-based injection filter remains a teaching stand-in.
- Added an opt-in local Qwen3 layer through Ollama for live-model comparison. The model is downloaded separately and its behavior is variable. The deterministic lab remains the reproducible control demonstration.
- Updated OWASP 2026 LLM references and clarified which capstone components exist in the prototype versus the wider paper design.
- Improved first-run setup, student navigation, Module 08–11 landing pages, Python 3.12 guidance, and lab profile/restart instructions after a fresh Windows walkthrough.
- Hardened the local lab and release delivery with localhost binding, bounded model access, dependency and workflow pins, and course checks on `main` pushes.

## Validation and scope

The release gate runs repository, content, workflow, instructor, site, and lab checks. A fresh Windows student walkthrough exercised the core BrokenPilot paths, the toy classifier, and the static MLOps evidence pack. The optional Qwen comparison was run with the course's specified local model; it did **not** execute the planted ticket or memory actions in those runs. The vulnerable deterministic BrokenPilot path did produce the state changes, while the tested controls stopped them.

The course uses fake local data and intentionally vulnerable profiles. It is not a production security control or an assurance claim about Qwen. This release does not claim an independent timed 40-hour student cohort, fresh macOS/Linux or Docker validation, or completion of optional DVAIA practice. See the [course lab index](../labs/RUNNABLE_AND_REASONING_LAB_INDEX.md) and [setup guide](https://github.com/stratomarco/ai-training-ml-security/blob/v1.2.0/docs/start-here/cross-platform-setup.md) for the supported route.
