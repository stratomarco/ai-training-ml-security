# AI Training: ML Security v1.3.0

This release extends the stable 12-module course with two optional offline supply-chain exercises and a published course website. BrokenPilot remains the primary hands-on target. The toy classifier and the static MLOps evidence pack retain their established roles, the local Qwen3 comparison is optional, and rubrics remain feedback aids.

## What changed since v1.2.0

- BrokenPilot's optional Mock Hub lab now lets students observe a fake credential leaking through diagnostics, use it to change an in-memory model revision, and compare diagnostic redaction with a read-only worker scope. No real registry, model file, or external Hub is involved.
- Module 08 has an optional artifact-promotion gate. It hashes fake artifact bytes and compares their metadata with a separate approval policy. The exercise demonstrates why a self-consistent manifest is insufficient when the artifact and manifest can both be replaced.
- The BrokenPilot Docker path now limits its build context and dependencies to runtime files and tightens container settings. Pull request checks exercise the Docker lab and the offline artifact cases on Windows.
- The [course website](https://stratomarco.github.io/ai-training-ml-security/) is published from `main` with a strict MkDocs build and GitHub Pages Actions deployment.

## Validation and limits

The release gate checks repository structure, course content, workflow configuration, strict MkDocs navigation, BrokenPilot, the toy classifier, and artifact-promotion cases. GitHub CI adds a Windows artifact check and a Docker smoke check. The published home page, Start Here, Mock Hub, and artifact-promotion pages were checked for reachability after deployment.

These labs use fake local data and intentionally vulnerable settings. The Mock Hub and artifact gate are separate simulations and do not share state. The artifact gate does not verify digital signatures, deserialize checkpoints, or prove model safety. The optional Qwen comparison remains variable and is not needed for the deterministic learning path. An independent first-time student and instructor pilot has not yet been completed; the [pilot guide](../instructor/field-pilot-v1.3.0.md) defines that follow-up.
