# AI Training: ML Security v1.3.0

This release adds two optional offline supply-chain exercises to the existing 12-module course. In BrokenPilot, a fake Mock Hub lets students compare credential exposure, diagnostic redaction, and least-privilege worker scope. The Module 08 artifact-promotion gate compares approved, tampered, and unapproved fake files without loading a model.

The [published course website](https://stratomarco.github.io/ai-training-ml-security/) now deploys from reviewed `main` changes. The BrokenPilot container path and CI checks have been strengthened. The deterministic BrokenPilot path remains the primary lab; Qwen3 and rubrics remain optional.

The labs use fake data. The two new simulations do not share state, and the promotion gate is not a digital-signature or model-safety system. Independent first-time student and instructor feedback is still pending. Read the [full release notes](https://github.com/stratomarco/ai-training-ml-security/blob/v1.3.0/release-notes/v1.3.0.md) for validation and limits.
