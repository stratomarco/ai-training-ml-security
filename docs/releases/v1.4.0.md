# AI Training: ML Security v1.4.0

This release improves the 40-hour learner route and adds a bounded, optional AIGoat v2.0 extension for two MCP trust-boundary exercises. Students can use an original source-review exercise without installing AIGoat. A contained Windows and Docker Desktop route is available for live traces of the same two cases.

The course website now maps edit links to canonical repository files and checks them during the build. The student workbook links each day directly to its modules, labs, journal, and final-report template. BrokenPilot remains the required local target; AIGoat, Qwen3, and rubrics remain optional.

The selected AIGoat route passed an isolated maintainer replay on one Windows host. A cold independent learner install, macOS, native Linux, other upstream exercises, and learning outcomes remain unverified. AIGoat stays under its own licenses, and paid use of its labs or prompts requires separate permission from its maintainers. Read the [full release notes](https://github.com/stratomarco/ai-training-ml-security/blob/v1.4.0/release-notes/v1.4.0.md) for validation and limits.
