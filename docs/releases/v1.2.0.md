# AI Training: ML Security v1.2.0

This stable teaching release centers the local BrokenPilot lab, with a guided browser path, fake-data ticket-to-agent exercise, named control profiles, and optional Qwen3 comparison. The separate toy classifier and MLOps evidence pack remain the supported classical-ML and supply-chain exercises.

The first-install student route now recommends Python 3.12, distinguishes runnable prototype behavior from paper-design analysis, and keeps DVAIA and rubrics optional. The model extension demonstrates variable behavior: the tested Qwen run did not perform the planted ticket or memory action.

The course uses intentionally vulnerable local fake data. Read the [full release notes](https://github.com/stratomarco/ai-training-ml-security/blob/v1.2.0/release-notes/v1.2.0.md) for validation and limits.
