# Version

Current release: **v1.4.0**. See the [release notes](releases/v1.4.0.md).

## Version meaning

- `v1.0.0`: first complete Markdown curriculum release.
- `v1.0.1`: review cleanup and reference fixes.
- `v1.1.0`: website edition with MkDocs Material, local preview, GitHub Pages workflow, and browsable course navigation.
- `v1.2.0`: BrokenPilot-first teaching release with the guided local lab, optional Qwen3 extension, and tested first-install course path.
- `v1.3.0`: optional offline supply-chain exercises, a restricted BrokenPilot container build context, and a published course website.
- `v1.4.0`: optional AIGoat MCP source and Windows live-trace exercises, improved learner routing, and verified source edit links.

## Status

Modules 01–12 are available. BrokenPilot is the primary runnable LLM, RAG, agent, and capstone target; the toy classifier and static MLOps evidence pack cover their own topics. The Mock Hub and artifact-promotion gate extend Module 08 as optional offline exercises. The AIGoat MCP extension and Qwen3 layer are optional, and rubrics are feedback aids.

## Current development focus

Maintain the supported student path and validate changes through the release gate. Further claims about learning outcomes require independent classroom use.
