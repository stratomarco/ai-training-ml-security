# How to Use This Course

Each module follows the same structure:

1. Read the module overview.
2. Review the slides.
3. Read the student handout.
4. Run the local lab or tabletop exercise where applicable; begin with the [lab setup overview](../lab-setup/overview.md).
5. Record the request, control state, observed result, and the security boundary involved.
6. Use the checklist or template to turn evidence into a short practical finding.
7. Use quizzes and rubrics as optional reflection or instructor feedback.
8. Review the instructor notes if you are teaching or self-studying.

## Learning mode

For self-study, complete one module at a time. Use BrokenPilot's guided browser workspace for local practice, then write down what the evidence proves and what it does not prove.

For instructor-led delivery, use the slides and instructor notes as the teaching backbone, then run the exercises as group work. Rubrics are optional guidance for feedback; the course does not require exam-style flag grading.

## Deliverables matter

The course is designed around practical security artifacts, not only attack demonstrations. Students should produce threat models, risk registers, red team reports, architecture reviews, and residual risk statements.
