# Labs

Start with the [runnable and reasoning lab index](RUNNABLE_AND_REASONING_LAB_INDEX.md). It maps each module to the correct target and prevents students from trying to reproduce classical ML or MLOps issues in BrokenPilot.

- [BrokenPilot](brokenpilot/prototype-app/README.md): course-owned LLM, RAG, agent, privacy, and capstone target.
- [Toy classifier](toy-ml-attacks/toy-classifier-app/README.md): local classical ML attacks for Modules 03 and 10.
- [MLOps evidence pack](mlops-supply-chain-labs/evidence-pack-review/README.md): static review for Module 08; do not execute its notebook.
- [AIGoat MCP trust-boundary review](aigoat-guides/mcp-trust-boundary-review.md): optional Module 07 source-review extension with upstream credit. A student runtime is not yet a supported setup path.
- [Student lab journal](STUDENT_LAB_JOURNAL_GUIDE.md): record request, control state, observed effect, security property, validation, and residual risk using the [template](../course-templates/student-lab-journal-template.md).

Start the required local target from its own README. DVAIA and the Qwen/Ollama layer are optional extensions.
