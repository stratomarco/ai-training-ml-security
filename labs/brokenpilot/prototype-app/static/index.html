Complete the standalone exercises first. For the live layer, install Ollama, pull qwen3:4b-instruct-2507-q4_K_M, stop the Docker lab if it uses port 8010, and run python run_lab.py --qwen --profile vulnerable. Refresh state to enable exercises 8 and 9.

Qwen responses vary. A model proposal is evidence of behavior, not authorization. BrokenPilot accepts only a bounded ticket proposal; its own code decides whether the tool runs. Use fake data only.

Local risk alert: This lab has no real user authentication. Any local API caller can reach the direct fake-ticket tool, and the vulnerable profile can change fake tickets. Keep BrokenPilot and Ollama on your own computer and never submit real documents, credentials, or system actions.
